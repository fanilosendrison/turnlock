## Review
- **Critical** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:412-455`: `requestDigest` and `groupSpecDigest` are only format-checked; no canonical preimage or recomputation is specified. Reusing a key and arbitrary equal `requestDigest` with different jobs is accepted, so idempotency is not bound to the request content.
- **Critical** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:434-444,448-455`: a child is spawned before its PID/state is durably recorded. A crash in that window leaves `dispatch-intent`; retry spawns another child, violating the stated exactly-one execution-group guarantee.
- **Critical** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:603-616`: retention deletes files before the sole atomic registry write. A crash after any deletion makes retry fail the required on-disk-file precondition, contradicting the required idempotent crash-retry behavior.
- **Critical** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:519,726,750-758`: the commitment is canonical-JSON digest plus byte size, not a raw-byte digest. Distinct valid JSON byte streams can have identical canonical JSON and byte size, allowing byte-level result modification to evade the immutability check.
- **Blocker** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:410-417,434,719-724`: target confinement/allocation validation is required before I/O, but the namespace identifier is generated only afterward. No resolver/mapping exists in public options, so `allocationId` matching cannot be deterministically validated.
- **Blocker** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:159-166,524-528,558-570,740-746,590-594`: failed/stopped jobs can have no result file, yet terminal reads and retention require one with a commitment. Such launches cannot be read, acknowledged, or fully cleaned up.
- **Blocker** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:513-522`: `readJobResult` mutates the registry without acquiring the mandatory single-writer lock, permitting lost updates against launcher/reconciliation/retention writes.
- **High** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:159-166,603-612`: the registry schema has no `retentionAcknowledged`, acknowledgement receipt, or deferred-cleanup timestamp despite the algorithm requiring all three. Durable retry and `earliestCleanupAtEpochMs` cannot be implemented from the declared record.
- **High** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:719-727,937-938`: path guidance does not require descriptor-based, no-follow exclusive creation. Pre-write resolution/checks are vulnerable to ancestor/result-path symlink replacement; tests cover only a preexisting final symlink, not the race or ancestor symlinks.
- **High** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:804-813`: stale-lock removal has a check-then-unlink race. A process can validate an old stale lock, another process can replace it with a valid lock, and the first process can unlink the valid replacement.
- **High** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:99-116,123,484-487,565`: the schema has no durable launcher PID/identity/status schema although inspection and stopping require it. Restart-safe liveness and signaling cannot be verified from the declared registry contract.
- **High** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:621-636,819-820`: documented named errors (`LaunchNotFoundError`, `IntegrityConflictError`, `RetentionConflictError`) are not declared/exported; only a generic error type is declared, and its shown constructor does not accept the two arguments used by the lock algorithm.
- **High** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:248-297,418,977-987`: resource-policy values have no runtime validity constraints; concurrency is hardcoded to `4`; and `resourcePolicyDigest` is referenced but absent from both options and registry. This contradicts the policy-derived-limit contract.
- **Medium** — `specs/working/proto-cdd-spec-turnlock-integration-v2.md:894-938`: required tests omit digest-preimage binding, spawn-before-durable-PID crash, concurrent `readJobResult` registry updates, failed/stopped result retention, retention-floor cleanup, malformed registry handling, and symlink TOCTOU/ancestor-symlink attacks.
